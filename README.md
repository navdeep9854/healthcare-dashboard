# Hospital Quality and EHR Adoption Dashboard

CMS hospital quality and EHR adoption analysis

**Live Dashboard:** https://public.tableau.com/app/profile/deep.kaur7386/viz/HospitalQualityandEHRAdoptionDashboard/U_S_HospitalQualityEHRAdoptionOverview

## Overview
Analysis of CMS Hospital General Information data (4,812 U.S. hospitals) covering 
EHR meaningful use adoption, overall quality ratings, and readmission performance.

## Key Findings
- **EHR Adoption:** 97% of hospitals (4,668 of 4,812) meet criteria for 
  meaningful use of Electronic Health Records.
- **Quality Ratings:** Most hospitals cluster around a 3-star overall rating 
  (1,761 hospitals), with only 82 hospitals (under 2%) achieving 5 stars.
- **Readmissions:** Hospital readmission performance is fairly balanced nationally — 
  866 hospitals perform better than average, 810 perform worse, and the largest 
  group (2,119) performs the same as the national average.

## Tools Used
Excel (pivot tables, data exploration), Tableau Public (dashboard visualization)

CMS Hospital General Information dataset
